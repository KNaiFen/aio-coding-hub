# 首页布局与可见项优化

## Goal

将首页概览重排为“左上紧凑用量、左下信息面板、右侧全高最近代理记录”，并让用户在设置页选择左下信息面板和配置信息 CLI 的显示项。

## Requirements

- 首页只保留新布局：`xl` 及以上为左侧 `5/12`、右侧 `7/12`；左侧用量图固定紧凑高度，日志占右列全高。
- 小于 `xl` 时按照“用量、信息、日志”纵向排列并允许滚动，不能因外层固定高度裁切内容。
- 首页不再展示热力图、供应商用量总览或“查看曲线/查看总览”切换；保留完整的“用量”页面。
- 保留现有首页用量统计开关。关闭时隐藏用量卡并停止首页曲线查询，信息面板补足左列空间。
- 设置页提供首页专属的五个信息面板与四个 CLI 显示开关；每类至少保留一个。
- 可见性偏好为本机 localStorage，不影响全局 CLI 顺序、供应商状态、路由、网关或其他页面。
- 解析或存储异常必须 fail-open，展示全部项目，且不得影响首页渲染。
- 不修改 Rust、IPC、数据库、设置文件结构或生成绑定；不在本地运行或编译 Rust。

## Acceptance Criteria

- [x] 桌面首页右侧日志卡贯穿概览高度，左列从上到下为紧凑用量与信息面板。
- [x] 窄窗口能滚动到所有区域，无横向溢出、重叠或裁切。
- [x] 可分别隐藏任意非最后一个信息面板和 CLI，顺序仍遵从现有排序设置。
- [x] 隐藏当前面板或 CLI 后回退到当前排序的第一个可见项；隐藏“熔断信息”时不因新熔断自动切换。
- [x] 无效、未来版本、重复或全隐藏偏好安全回退，首页保持可用。
- [x] 最近代理记录的刷新和简洁模式控制仍可用，且不被强制切换。
- [x] 前端单元测试、类型检查、Lint、构建和视觉验证通过；本地 Rust 命令未执行。

## Notes

- 旧的 `aio-home-overview-logs-primary-layout` 是无效遗留值，不迁移、不再影响新布局。
- `show_home_heatmap` 后端字段保留兼容，但不再影响首页，也不再提供首页设置控件。
