# 技术设计

## 状态所有权

React Query 继续拥有查询数据、错误和五秒心跳。组件使用 `isLoading` 表示唯一的首次无数据加载；通用 `isFetching` 不再驱动可见内容。组件新增本地 `manualRefreshing` 和同步 ref 锁，包裹现有 `refreshProviderAccountUsage`，在 `finally` 中释放。

## 渲染规则

- `isLoading`：显示“账户: 刷新中”，隐藏指标，固定图标可旋转。
- 后台 `isFetching`：渲染查询开始前的摘要、指标、错误和按钮状态，不显示任何自动刷新反馈。
- `manualRefreshing`：保留已有摘要/指标，只让固定 `h-3 w-3` 图标旋转并禁用按钮；无可显示数据时仍使用单行加载文案。
- 请求完成：成功使用新 data；错误使用现有错误格式化并隐藏旧指标。结果 DTO 自身的失败/过期语义保持不变。

## 测试策略

新增组件级 fake-timer 测试直接覆盖多卡和三个心跳周期，并更新卡片集成测试的手动刷新可访问名称与稳定内容断言。查询 hook 接口不变，现有五秒心跳契约测试继续作为后端租约保护。
