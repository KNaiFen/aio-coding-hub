# 统一 TUI 顶部摘要与本地时区显示

## Goal

精简独立 TUI 的共享顶部摘要，让请求视图与供应商视图使用完全相同、可稳定扫读的两行信息；同时让供应商详情中的短期可用性时间段按运行 TUI 的系统时区显示，不再附加误导性的 `UTC` 标记。

## Requirements

- 请求视图和供应商视图必须共用同一个顶部摘要，不再根据当前视图显示“请求”或“供应商”。
- 顶部摘要第一行固定为 `并发 <数量> | 首选 <供应商>`。
- 顶部摘要第二行固定为 `<CLI> | 今日 <费用> | <Token>`。
- 移除顶部摘要中的 `AIO 在线/离线/连接中` 文案；现有列表空态和离线重试行为保持不变。
- 首选供应商、今日费用或 Token 暂不可用时继续使用安全占位，不因缺少快照而崩溃。
- 两行摘要继续遵循现有 Unicode 显示宽度截断，在窄终端中不得溢出。
- 供应商详情的每个短期可用性时间段必须把协议中的 Unix 时间戳转换为 TUI 所在系统的本地时区后显示。
- 时间段保持 `HH:MM-HH:MM` 格式，不显示 `UTC` 或其他额外时区后缀。
- 本次不修改观测协议、供应商可用性统计边界、路由、余额刷新、轮询频率或视图切换交互。
- 改动合并后按仓库默认规则发布补丁版本，并交付现有发布矩阵的 TUI 与桌面资产。

## Acceptance Criteria

- [x] 请求视图与供应商视图渲染出的顶部两行内容完全一致。
- [x] 示例快照显示为第一行 `并发 1 | 首选 INPUT 大春`，第二行 `Codex | 今日 $118.69 | 194M`。
- [x] 顶部摘要不再出现 `AIO 在线`、`请求` 或 `供应商` 视图标签。
- [x] 无快照或部分字段不可用时仍显示两行有界占位内容。
- [x] 窄终端下两行内容按现有 CJK/Unicode 宽度规则截断且不溢出。
- [x] 供应商详情时间段使用系统本地时区，且渲染文本中不包含 `UTC`。
- [x] 回归测试覆盖两种视图的共享摘要，以及非零时区偏移下的分钟换算。
- [x] 仅由 GitHub Actions 执行并通过 Rust 格式、锁文件、测试、Clippy 和原生构建验证。
- [x] 变更通过 `origin` 的 PR 合并到 `main`，补丁版本 Release 发布成功且交付资产完整。
