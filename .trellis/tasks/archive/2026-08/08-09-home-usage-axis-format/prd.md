# 首页用量 Y 轴格式与宽度

## Goal

消除大数用量刻度裁切，且轴宽能随更长标签扩展。

## Requirements

- `>=1_000_000_000` 显示为一位小数的 B；低值格式不变。
- 宽度由实际 tick 最长格式文本计算，最小 45px，不用新的固定宽度掩盖问题。
- 实施与测试代码完成后等待父任务统一验证。

## Acceptance Criteria

- [ ] `1_000_000_000` 格式化为 `1.0B`。
- [ ] 超长刻度使 YAxis width 大于 45，普通标签保持最小宽度。
- [ ] Tooltip 与 Y 轴使用同一格式。
