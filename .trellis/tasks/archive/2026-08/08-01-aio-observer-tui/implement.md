# 实施清单：AIO 本地观测服务与 SSH TUI

1. 建立共享协议 crate、TUI crate 和 workspace 配置；定义版本化、脱敏、可部分失败的 DTO 与描述文件格式。
2. 在桌面运行时接入本地观测服务：随机回环端口、令牌鉴权、描述文件生命周期、只读快照查询、缓存、超时和熔断 peek。
3. 抽取服务端模型推理判定与日志投影，保证状态栏统计和首页并发语义一致；增加请求/路由/用量聚合测试。
4. 实现 `aio-tui` 的状态栏、日志列表、详情、键盘交互、离线重连、终端恢复与 CJK 宽度处理。
5. 扩展 Release 工作流和支持矩阵，打包四平台 TUI 制品及校验和；保持 updater 清单仅含桌面制品。
6. 更新后端和跨层 Trellis 规范，记录本地观测协议与“不影响网关”的不变量。
7. 本地运行仅 Node/静态检查；将 Rust 格式化、测试、Clippy、四平台构建和发布验证交由 PR/main CI。所有检查通过后再提交、推送、合并和打标签。

## 回滚点

- 观测服务完全独立于网关监听器与转发任务；必要时可在单独提交中移除启动调用，恢复原行为。
- TUI 制品不纳入自动更新器，发布问题可仅撤回独立资产而不影响桌面更新。
