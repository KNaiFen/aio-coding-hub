# 供应商状态条三色规则

## Goal

为历史格增加中间健康状态，并使当前格反映最新观测是否成功。

## Requirements

- 过去格 `<50%` 红、`>=50% && <90%` 黄、`>=90%` 绿，空格灰。
- 当前格最后失败为红；最后成功时按 90% 分黄/绿。
- 只有包含 `now` 的格是当前格；未来格无数据。同毫秒时失败优先。
- 实施与测试代码完成后等待父任务统一验证。

## Acceptance Criteria

- [ ] Rust/TS 枚举增加 `degraded`，使用现有 warning 色。
- [ ] 49%、50%、89%、90% 和 no-data 的边界测试完整。
- [ ] 混合成功/失败的当前格按最后观测决定。
