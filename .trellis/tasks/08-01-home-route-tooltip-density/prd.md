# 首页代理链提示与摘要密度修复

## Goal

修复首页最近代理记录中代理链详情的主题与拥挤问题，并用稳定、可读的短标签替代容易换行的长句摘要。

## Requirements

- 代理链详情必须在明暗主题下都使用当前主题的面板颜色，不能继续呈现反向主题或低对比文字。
- 详情面板必须能容纳较长供应商名、错误原因和多跳链路，并在视口边缘自动避让；内容过多时允许在面板内滚动。
- 每一跳使用清晰的两层信息结构，已由中文状态表达的内部 `decision` 或已知英文原因不重复展示；未知未来原因仍应安全换行显示。
- 首页卡片中的链路摘要保持单行，数字采用等宽表格数字，使用 `直连`、`切N`、`跳N`、`重N`、`请N` 等短标签。
- `切` 表示供应商迁移次数，`跳` 表示未实际发出请求的候选供应商，`重` 表示同供应商额外重试次数，`请` 表示实际向上游发出的请求次数。
- 短标签不得改变完整自然语言摘要；完整摘要继续提供给详情面板和辅助技术。
- 畸形或未来版本的链路数据必须 fail-open：隐藏无法理解的细节或使用安全回退，不能使首页渲染失败。
- 普通单行 Tooltip 的现有反色视觉与交互保持不变。
- 不修改后端、数据库、请求转发、重试、熔断或持久化语义。

## Acceptance Criteria

- [x] 明暗主题中的代理链详情都使用语义化面板颜色并保持可读对比度。
- [x] 长内容、多跳内容和视口边缘场景不溢出屏幕，必要时可在详情面板内滚动。
- [x] 截图中的两次跳过后直连场景显示 `切2·跳2·请1`，且不会换行。
- [x] 同供应商三次实际请求显示 `重2·请3`；两次实际请求发生一次供应商切换显示 `切1·请2`。
- [x] 已知重复内部原因被收敛，未知原始原因仍可见且安全换行。
- [x] 普通 Tooltip 样式没有视觉回归。
- [x] 目标单元/组件测试、TypeScript 类型检查、ESLint 和 Vite 前端构建通过。
- [x] 使用 Playwright 覆盖明暗主题、窄/宽视口和长链路渲染；不运行任何本地 Rust/Cargo/Tauri 命令。
