# 缓冲请求日志实时刷新

## Goal

顶部无闪烁实时更新，离顶冻结展示并提示新请求。

## Requirements

- 列表位于顶部时继续自动刷新，但 placeholder 期间保留旧行直到新快照原子替换。
- 离顶部超过 4px 时冻结持久日志、活跃请求、trace 卡片和活动时钟的完整展示投影。
- 数据源继续刷新，并以当前筛选下最新总数与冻结总数之差显示“有 N 条新请求”。
- 点击提示、手动刷新、筛选、分页或页大小变化时解除冻结并同步回到顶部。
- 前后台切换沿用现有补拉规则；离顶时只更新待展示数量。

## Acceptance Criteria

- [ ] 顶部自动刷新不出现空列表或高度归零闪烁。
- [ ] 离顶后所有会改变列表高度的投影保持稳定，当前阅读位置不跳动。
- [ ] 待展示数量不会因重复 complete 信号或合并刷新重复计数。
- [ ] 点击提示后回到顶部、清零提示并刷新一次。
- [ ] 首页对共享日志面板的既有调用行为不变。

## Notes

- 后端稳定快照与分页合同不变；问题限定在日志页展示与实时刷新协调。
