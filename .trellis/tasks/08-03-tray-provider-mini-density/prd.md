# 压缩 Tray 供应商小窗密度

## Goal

将 macOS Tray 供应商 mini 面板的单行高度从 36px 收紧到 24px，并同步前端滚动上限与原生窗口几何。

## Requirements

- 每个供应商继续独占一行，保留名称、不可用原因标记、18 格可用性条和成功/失败计数。
- 前端行高固定为 24px，十行滚动容器上限固定为 240px。
- 原生 `TRAY_PROVIDER_MINI_ROW_HEIGHT` 同步为 24，最多十行和空状态计算保持现有规则。
- 标题栏、面板宽度、圆角、毛玻璃、空状态、悬停关闭、快照冻结和滚动回顶行为不变。
- 按用户决定不增加截图、DPR 或实体屏视觉门禁。

## Acceptance Criteria

- [ ] 1、5、10 个供应商的逻辑窗口高度分别为 68、164、284px；0 个供应商仍为 112px。
- [ ] 超过 10 个供应商时窗口保持 284px，前端保留所有行并可内部滚动。
- [ ] 行内 18px 标记、文本、18 格状态条和计数垂直居中且测试契约不丢失。
- [ ] 新快照仍将滚动位置重置到顶部，标题和空状态尺寸不变。
- [ ] 前端测试通过，Rust 几何测试由 GitHub Actions 通过。
