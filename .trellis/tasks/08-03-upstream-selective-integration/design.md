# 选择性上游集成设计

## 边界

- 父任务只负责来源固定、子任务顺序、跨任务验收和最终发布；产品代码由子任务拥有。
- 所有子任务从最新 `origin/main` 建立短分支，使用完整 SHA 记录来源，禁止携带上游 Trellis、版本和锁文件。
- 发生 fork 产品语义冲突时停止对应子任务并提交具体证据，不替其他子任务做隐式决定。

## 集成结构

1. ChatGPT account header 隔离。
2. Provider 删除缓存与历史身份收敛。
3. OAuth 状态缓存竞态修复。
4. Claude OAuth 候选适配与人工门禁。
5. ledger Provider 性能趋势与共同资源预算。
6. About 未知元数据隐藏。

## 发布与回滚

- 每个子任务形成独立原子提交；集成分支按上述顺序吸收。
- UPA-004 候选提交在人工门禁前不得进入集成发布。
- 任一子任务可单独 revert，不需要数据库降级；UPA-008 不创建 schema 或持久聚合表。
