# AIO 悬浮窗状态条与液态背景

## Goal

在不降低供应商扫描效率的前提下，减少“成/败”文字噪声、拉长状态条、给供应商状态字留出稳定空间，并让悬浮窗呈现明确可见的半透明液态材质。

## Requirements

- 删除状态条右侧可见的“成”“败”两个字；完整含义仍通过颜色、无障碍名称和 tooltip 保留。
- 只显示绿色成功数字与红色失败数字，使用等宽表格数字，预留足够宽度并保持明显间隔。
- 将释放的横向空间用于加长状态条并整体左移。
- 供应商列为右侧“熔”“冷”“限”等状态字额外预留至少一个汉字宽度，长供应商名仍截断且 `title` 保留完整名称。
- 现有状态字去重、18 格数据契约、快照冻结、十行滚动和窗口定位行为保持不变。
- 半透明背景必须在 macOS 原生窗口中实际可见；不能把浏览器中的普通透明色等同于原生液态材质。

## Acceptance Criteria

- [ ] 可见 DOM 不再出现“成”“败”，成功/失败精确值仍可由无障碍名称和 tooltip 获取。
- [ ] 状态条比当前 170px 更长、位置更靠左，18 格保持等宽且不挤压。
- [ ] 供应商名、一个或多个状态字、状态条及两组数字在 404px 窗口内不重叠。
- [ ] 10 行滚动、快照更新回顶、紧凑计数边界和原生几何测试保持有效或按新契约同步更新。
- [ ] 浏览器结构测试通过；macOS 原生材质通过 GitHub Actions 产物人工截图验收。

## Locked Decisions

- 使用 Apple 风格静态 Liquid Glass：原生毛玻璃、明确半透明、边缘高光和层次，不加入动态折射动画。
- 用户实测当前悬浮窗是不透明的；验收必须以 macOS 原生窗口透出桌面背景为准，不能只检查 CSS 类名。
- 横向 tracks 锁定为 `92px / 198px / 72px`，数字区为两个 32px 数值加 8px 间隔，状态字区域固定预留 40px。
