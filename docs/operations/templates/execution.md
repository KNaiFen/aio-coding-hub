填好交付报告、把最新 PR CI 跑绿并标记可评审后，停止修改 worktree，通知 main 验收。

## 停止并询问 main

出现以下任一情况时不要自行扩大任务：

- 用户锁定决定与当前代码或现行合同冲突。
- 必须修改“允许修改”之外的重要模块或公共接口。
- 发现与其他活动 worktree 的语义冲突或依赖顺序变化。
- 需要破坏兼容性、迁移用户数据、使用真实账号/凭据或执行高风险操作。
- 无法满足某条 AC，或者只能通过明显不同的方案满足。
- CI 失败疑似基础设施或 main 上已有问题，且没有任务内的可靠修法。
